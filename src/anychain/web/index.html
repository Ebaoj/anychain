Configurações

Rede

Qualquer rede EVM com um explorador Blockscout. A rede fica salva só neste computador (o endereço do nó pode ter uma chave).

Modelo que escreve as respostas

A chave fica salva só neste computador e nunca é mostrada de novo. Toda resposta é conferida contra os fatos, qualquer que seja o modelo.

Idioma

O que aconteceu com a transação?

Converse com o assistente: mande o código de uma transação e pergunte o que quiser. Cada resposta traz a prova do que diz. Escolha como você vai usar:

🛍️Lojista Para entender um pagamento sem termos técnicos.
  • Resposta em linguagem simples
  • O que fazer agora
  • Provas guardadas, se quiser ver
 💻Desenvolvedor Para depurar uma chamada que falhou.
  • Chamada decodificada e código
  • Fatos e fontes sempre à vista
  • Leituras no nó pela conversa
 🔍Auditor Para revisar risco e permissões.
  • Notas de segurança primeiro
  • Quem pode chamar a função
  • O que não foi possível verificar
